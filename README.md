# Trading Simulator Platform Visio

A paper trading simulation platform that uses market price data to simulate stock trades, track portfolio performance, and analyse trading decisions.

## Project Goal

The aim of this project is to build a finance-focused web application where users can simulate buying and selling stocks without using real money. The platform will include stock price data, portfolio tracking, trade history, and performance analysis.

## Planned Features

- Search for stock tickers
- View current or delayed market prices
- Simulate buy and sell trades
- Track cash balance and holdings
- Calculate profit and loss
- Store trade history
- Display portfolio charts
- Analyse portfolio performance

## Tech Stack

- Python
- FastAPI
- React
- SQLite
- Finnhub API
- GitHub
